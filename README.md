# Հաճախորդների վարքագծային տվյալների հիման վրա սեգմենտավորման և դասակարգման համակարգի մշակում

## Նախագծի նկարագրություն

Նախագծի նպատակն է հաճախորդների վարքագծային տվյալների վերլուծության միջոցով իրականացնել հաճախորդների սեգմենտավորում և դասակարգում։

## Օգտագործվող տեխնոլոգիաներ

- Microsoft Fabric
- Python
- PySpark
- Pandas
- Scikit-learn
- Lakehouse

## Տվյալների մշակում

Տվյալների մշակման համար կիրառվում է Medallion Architecture մոտեցումը՝ Bronze և Silver շերտերով։

## Իրականացվող գործընթացներ

- Տվյալների ներբեռնում և ուսումնասիրություն
- Տվյալների մաքրում և նախապատրաստում
- RFM վերլուծություն
- Հաճախորդների սեգմենտավորում՝ K-Means ալգորիթմով
- Դասակարգման մոդելի մշակում և գնահատում

## Նախագծի միջավայրը

Տվյալների մշակման և վերլուծության աշխատանքներն իրականացվում են Microsoft Fabric միջավայրում։
